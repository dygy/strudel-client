# Using Strudel with an AI assistant

An assistant that speaks the Model Context Protocol (MCP) can read and change your track library, look up Strudel's functions and sounds, check code for mistakes, and, if you allow it, control the music in an open tab.

You sign in to Strudel yourself and approve the connection. The assistant only ever acts as you, on your own tracks, and you can end the connection at any time.

## Connect an assistant

The address of the server is:

```
https://strudel.dygy.app/mcp
```

### Claude on the web and Claude desktop

1. Open **Settings**, then **Connectors**.
2. Choose **Add custom connector** and paste the address above.
3. Sign in to Strudel when asked, and press **Allow**.

### Claude Code

```sh
claude mcp add --transport http strudel https://strudel.dygy.app/mcp
```

Then run `/mcp` in Claude Code, choose `strudel` and sign in when your browser opens.

### Other assistants

Any assistant that supports remote MCP servers with OAuth can connect. Give it the address above, and sign in when it asks.

## What an assistant can do

**Read your library.** `list_folders`, `search_tracks` and `get_track`. Search looks at track names and code. In a multitrack it only looks at the code of the active step.

**Change your library.** `create_track`, `update_track`, `move_track`, `set_track_steps`, `create_folder`, `rename_folder` and `move_folder`. The same naming rules apply as in the app. Each change says which version it read. If the track has changed since, the change is refused and the assistant has to read it again, so it can't overwrite your work without seeing it.

**Delete.** `delete_track`, `delete_step` and `delete_empty_folder`, one item at a time. `set_track_steps` can drop steps too, but only ones it lists by name. There is no trash, so assistants are told to ask you first. A folder with anything in it can't be deleted this way.

**Look things up and check code.** `lookup_function`, `search_functions`, `list_sounds` and `check_code`. The check finds syntax mistakes, mini-notation mistakes and names that don't exist, without running anything. Online it takes code up to 512 bytes.

**Control an open tab.** `list_tabs`, `play`, `stop`, `update_code` and `open_track`. See below.

If a track in your library holds text aimed at an assistant, assistants are told to treat it as your data, not as instructions. That is a request to the assistant rather than a guarantee, so be careful about pasting in code you don't trust.

## Letting an assistant control a tab

Control is off in every tab until you turn on **Allow assistant control**, in Settings or, on a phone, in the menu. While it's on, the tab shows an indicator with a button to turn it off. It also turns off when you reload or close the tab, or sign out. Whatever an assistant had waiting when you turn it off isn't done.

- **Updating the track that's playing** changes the code with no gap or fade, the same as pressing Update. An assistant has to name the track it means, and is refused if something else is open by then.
- **Only playing changes what you hear.** If the editor holds a different track from the one playing, or nothing is playing, an update only changes the text.
- **Opening another track and playing it** uses the transition selected in that tab. While a track is switching, other actions are refused.
- **Code with a mistake** leaves the music playing. The assistant gets the error, and the tab shows it. The code stays in the editor, as if you'd typed it, and autosave treats it the same way, so press Undo if you'd rather not keep it.
- **Anything you typed** in that track is saved before an assistant's code replaces it. If that save fails, the assistant is refused and your editor isn't touched. Undo brings your text back.
- **A headphone preview** keeps playing.
- **If the "changed elsewhere" message is showing**, assistants are refused in that tab until you choose.

With two tabs allowed, an assistant has to say which one it means. In zen mode a tab has no library, so an assistant can't open a track there.

## Disconnecting

In Strudel, open **Settings** and find **Connected assistants**. Press **Disconnect** next to the assistant. This ends its access through Strudel at once. A copy of its access key that the assistant kept can still reach your data for up to an hour, until the key runs out.
